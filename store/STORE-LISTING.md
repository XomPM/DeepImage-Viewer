  DeepImage Viewer is a classic Win32 desktop application (Direct2D/Direct3D) that opens image, 3D model and G-code files chosen by the user and provides File Explorer thumbnails for 3D formats through a COM thumbnail handler. It requires full trust to run as a desktop app and to register the thumbnail handler. It does not collect data or access the network in the background.

## 한국어 (ko-KR)

**짧은 설명 (Short description)**
사진과 3D 모델, G-code 미리보기를 한 화면에서. 빠르고 가벼운 이미지 + 3D 뷰어.

**설명 (Description)**
DeepImage Viewer는 사진과 3D 파일을 한 프로그램에서 빠르게 여는 Windows용 뷰어입니다.

• 이미지: JPG, PNG, GIF(애니메이션), WebP, HEIC, AVIF, TIFF, BMP, SVG, PSD, TGA, RAW 등
• 3D 모델: STL, 3MF, OBJ, PLY, glTF/GLB, FBX, STEP/STP, IGES/IGS, BREP, DAE, 3DS, AMF — 색상과 조립 구조 그대로 표시
• G-code: PrusaSlicer · Orca Slicer · Bambu Studio · Creality Print가 넣은 미리보기 이미지 표시 (.gcode / .bgcode)
• 파일 탐색기 썸네일: 3D 파일과 G-code도 아이콘 대신 미리보기로 (3MF는 슬라이서 플레이트 이미지 우선)
• 두 이미지 비교 모드, 전체 보기 · 화면 꽉 차게 · 폭/높이 맞춤 · 1:1 (선택 기억)
• 펜 · 형광펜 · 도형 · 모자이크 · 마스크 표시 도구
• 자르기, 크기 조절, 밝기 · 대비 · 색 보정, 다른 형식으로 저장
• EXIF 촬영 정보와 히스토그램
• Windows 라이트/다크 테마와 강조색에 맞춰 바뀌는 디자인, 한국어/English
• x64와 ARM64(Snapdragon) 네이티브 지원, 빠른 시작

3D 보기 화면의 "3D프린팅" 버튼으로 3DMIND 출력 제작 요청도 바로 할 수 있습니다.

## English (en-US)

**Short description**
Photos, 3D models and G-code previews in one fast, lightweight viewer.

**Description**
DeepImage Viewer opens your photos and 3D files in one fast native Windows app.

• Images: JPG, PNG, animated GIF, WebP, HEIC, AVIF, TIFF, BMP, SVG, PSD, TGA, RAW and more
• 3D models: STL, 3MF, OBJ, PLY, glTF/GLB, FBX, STEP/STP, IGES/IGS, BREP, DAE, 3DS, AMF — with colours and assemblies
• G-code: shows the preview embedded by PrusaSlicer, Orca Slicer, Bambu Studio and Creality Print (.gcode / .bgcode)
• File Explorer thumbnails for 3D files and G-code (3MF uses the slicer's plate image first)
• Side-by-side compare, fit / fill / fit width / fit height / 1:1 (remembered)
• Markup: pen, highlighter, shapes, mosaic and mask
• Crop, resize, brightness / contrast / colour adjustments, save as another format
• EXIF details and histogram
• Follows the Windows light/dark theme and accent colour; Korean and English
• Native x64 and ARM64, starts instantly
